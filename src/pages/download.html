Android

Install directly, in a minute

The Coopvest Africa app is available for Android as a direct download. Tap the button, allow the install, and sign in with the details your employer or our team gave you.

Download for Android (APK) Release notes
  • Version — 1.0.0 (build 236).
  • Size — about 84 MB.
  • Requires — Android 7.0 (API 24) or newer.
  • Works on — 32-bit and 64-bit devices (universal build).

Before you install

Because this is a direct download rather than a store install, Android will ask you to allow installation from your browser. That prompt is normal — it is Android confirming you chose to install this app.

Only install from this page

Download the APK using the link on this page, or from our official GitHub release. We do not distribute the app through file-sharing sites, and we will never ask you to install an APK sent by message.

Setup

How to install

Download the APK

Tap Download for Android on this page. The file is about 84 MB, so a Wi-Fi connection is quicker.

Allow the install

Android will warn that the file comes from your browser. Choose to allow it for this one install, then open the downloaded file.

Install and open

Confirm the install, open Coopvest, and allow notifications if you would like reminders about contributions and repayments.

Sign in

Use the email address registered with your employer or with us. If you have not joined yet, contact us to get started.

Questions

Download FAQs

Why is the app not on the Play Store?

We publish directly to make the app available to every member immediately, without waiting on store review. A Play Store listing may follow.

Is it safe to install an APK?

The file is built automatically from our own source code by our build system and published to our official release page. Download it only from this page or that release page.

If you would like to verify the file, the release notes list a SHA-256 checksum for each build.

Android blocked the install. What now?

Open your device settings, find the browser you downloaded with, and enable permission to install unknown apps for it. Then open the downloaded file again. The exact wording varies by phone manufacturer.

Is there an iPhone version?

The app is Android only at present. An iOS build is in progress. Until then, please contact us and we will help you manage your account.

How do I update to a newer version?

Download the latest APK from this page again and install it over your existing app. Your data and login are not affected.

The app will not run on my phone.

The app requires Android 7.0 (API 24) or newer. To check, open Settings → About phone → Android version. If your phone is older, contact us for help with your account.
